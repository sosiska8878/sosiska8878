## О проекте

**Graphite** — это лёгкий редактор заметок в браузере. Он работает по принципу **local-first**: вы открываете папку со своими `.md`-файлами, редактируете их, а данные не уходят на сервер.

Проект сделан как эксперимент в «вайбкодинге»: полностью за один день, через бесплатную версию DeepSeek, без участия человека. Это не попытка заменить Obsidian, а попытка сделать максимально простой и честный инструмент для заметок.

## Возможности

- 📝 Редактирование Markdown-заметок прямо в браузере
- 📁 Открытие локальной папки с файлами `.md` через File System Access API
- 🔒 Local-first: без регистрации, аккаунтов и загрузки данных на сервер
- 🌙 Тёмная тема
- 🧭 Онбординг для первого запуска
- 🧱 Статический сайт, размещённый на GitHub Pages

## Ограничения

- Для открытия папок нужен браузер на Chromium: **Chrome, Edge или Opera**.
- В Firefox и Safari доступ к локальным папкам пока ограничен — можно начать без папки.
- Это **early preview**: возможны шероховатости и недоработки.

## Быстрый старт

1. Откройте [демо](https://sosiska8878.github.io/sosiska8878/).
2. Нажмите кнопку начала работы.
3. Выберите локальную папку с заметками — или начните без папки.
4. Пишите Markdown. Всё остаётся у вас.

## Локальный запуск

Проект представляет собой статический сайт. Клонируйте репозиторий и запустите любой статический сервер:

```bash
git clone https://github.com/sosiska8878/sosiska8878.git
cd sosiska8878
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

Как это сделано

Graphite написан за один день в режиме вайбкодинга: идея, код и интерфейс собраны в диалоге с бесплатной версией DeepSeek. Человек не писал код вручную — только ставил задачу и принимал результат. Это часть эксперимента: насколько далеко можно зайти с текущими моделями, если не бояться пробовать.
